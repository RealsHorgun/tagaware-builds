# Tag-a-War(e) playtest builds

Minigame movement tag. The sides swap on the beat.

**[Download the latest build](https://github.com/RealsHorgun/tagaware-builds/releases/latest/download/TagAWare.zip)** (Windows)

1. Open Steam and stay signed in.
2. Unzip the folder somewhere you own, like Documents. Keep the files together.
3. Run `TagAWare.exe`. The game updates itself after that.

PLAY_ME.txt in the zip has the rest. This repo only holds the built game;
see LICENSE.txt for what you can do with it (streaming and videos are welcome).
